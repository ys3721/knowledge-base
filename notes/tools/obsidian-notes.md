# Obsidian 笔记方法

## 为什么适合当知识库的数据源

Obsidian 的 vault 就是一个普通文件夹，里面全是 Markdown 纯文本，
没有数据库、没有专有格式，任何脚本都能直接读，也方便 git 版本管理。

## 常用能力

- 双向链接 [[笔记名]]，把零散笔记连成网。
- 标签 #topic/子话题，比文件夹灵活。
- Dataview 插件可以按元数据查询笔记，生成索引页。
- 图谱视图能看到哪些笔记是孤岛。

## 和 AI 结合的方式

把 vault 目录交给检索脚本索引，AI 通过 MCP 或命令行查笔记；
Obsidian 继续负责写和读，AI 负责检索和总结，两边共用同一批文件。
